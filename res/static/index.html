The Product.

Our debut public release is Summon Style: Hardline,
a world-scale visual style system for Unity.

Summon Style: Hardline provides a fully featured style system for flat-gradient cel-shaded, comic-esque worlds.

Built for production teams, Hardline gives art and tech complete control over a single, global visual language, letting you author, save, and blend full-world looks in seconds without fighting lights, probes, or per-material hacks.

It scales from indie scenes to large environments with predictable performance, so designers can push bold, illustrated worlds while engineers keep rendering fast, stable, and easy to integrate.
